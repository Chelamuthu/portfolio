MZAptiCode+ ⭐ Flagship Project

Node.jsExpressMSSQLOllama (Qwen3)Judge0

Problem: Students need continuous, personalized programming and aptitude practice, but traditional platforms give only static questions and manual evaluation.

Solution: An AI-powered self-learning platform covering 78 aptitude topics and 5 programming languages, with an AI pipeline that generates follow-up coding questions, verifies their logic against the original concept, and automatically regenerates them if validation fails. A two-stage submission gate runs test cases first, then an AI logic check to catch hardcoded or bypassed solutions. Currently live and actively used in college labs, with automatic internal-mark calculation.

ESP32CAN BusLoRaNode.jsFlutter

Problem: The Zion Racing EV Go-Kart team had no reliable way to monitor ignition status, battery health, and vehicle position during competitions.

Solution: Built a real-time monitoring system reading CAN Bus and sensor data on an ESP32, streaming it over LoRa/GSM to a live web and Flutter mobile dashboard for the pit crew — covering battery status, ignition detection, and GPS tracking. As Telemetry Head and Innovation Lead, I led its design and helped the team win Runner-Up for Best EV Innovation.

EmpQuery — HR Employee Chatbot
